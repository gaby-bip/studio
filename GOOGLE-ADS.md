# Google Ads: palavras-chave e anúncios por nicho

Cada grupo de anúncios leva para o link do seu nicho. A página abre na aba certa e o título do topo muda para o nicho, com as mesmas palavras da busca.

> Os links abaixo supõem que as páginas no WordPress se chamam `/templates/` e `/modelos-loja/`. Se forem outros, troque nos anúncios.

**Como usar as palavras-chave**
- `"entre aspas"` = correspondência de frase (a busca contém a expressão).
- `[entre colchetes]` = correspondência exata (a busca é a expressão ou quase).
- Comece com frase e exata. Evite a correspondência ampla no 1º mês: ela gasta a verba com buscas pouco ligadas ao seu serviço.
- Toda semana, abra o relatório **Termos de pesquisa** e transforme buscas ruins em palavras negativas.
- Antes de subir, confira volume e custo por clique no **Planejador de Palavras-chave** (de graça, dentro do Google Ads). Os termos abaixo são uma lista inicial, não dados de busca.

## Palavras negativas (para as duas campanhas)

Adicione como **lista de palavras-chave negativas** e aplique nas duas campanhas:
```
grátis
gratis
gratuito
gratuita
free
curso
aula
como fazer
como criar
tutorial
aprender
template grátis
download
baixar
modelo pronto grátis
vaga
emprego
freelancer
wix
canva
```

Por que alguns termos estão aqui:
- **curso, como fazer, tutorial:** a pessoa quer aprender a fazer sozinha, não contratar.
- **template grátis, download, baixar:** a pessoa quer um arquivo pronto e não vai pagar pelo serviço.
- **wix, canva:** a pessoa procura uma ferramenta para fazer o site sozinha. Tire da lista se quiser disputar esse público.
- Não negative **"preço"** nem **"quanto custa"**: quem pesquisa preço costuma estar perto de contratar.

## Textos com palavras-chave nas páginas

Para o Google entender que a página combina com o anúncio, as palavras principais aparecem no texto:

| Onde | Página de site | Página de loja |
|---|---|---|
| Título da aba do navegador | Criação de site para academia e personal trainer | Criação de loja virtual para roupas e acessórios |
| Título do topo (padrão) | Site para academia e personal trainer | Loja virtual para roupas e acessórios |
| Título do topo (link `#academia` / `#moda`) | Site para academia… | Loja virtual de roupas… |
| Título do topo (link `#personal` / `#acessorios`) | Site para personal trainer… | Loja virtual de acessórios… |
| Título de cada aba de modelos | Modelos de site para academia… / para personal trainer | Modelos de loja virtual de roupas / de acessórios… |

No Elementor, o `<title>` e a descrição dos arquivos HTML não valem: configure-os em **Editar página → SEO** (Yoast, Rank Math ou o plugin que você usar). Use os mesmos textos da tabela acima.
